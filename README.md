# Campus Life Super App — MVP

## About the Project

The Campus Life Super App is a student project designed to help college students find campus events, search for locations, and check the local weather in one place.

## Project Files

- `index.html` — Home page and weather widget
- `events.html` — Campus event search and category filters
- `map.html` — Location search and interactive map
- `css/style.css` — Custom website styling
- `js/script.js` — JavaScript interactions and API connections
- `images/` — Optional folder for images

## Features

- Three connected HTML pages
- Bootstrap navigation and responsive layouts
- Custom CSS styling
- Event search and category filtering
- Save-event buttons
- Current weather from the Open-Meteo API
- Location search using OpenStreetMap

## How to Run the Project

1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select Open with Live Server.
6. Test all three pages and their features.

An internet connection is needed for Bootstrap and the API features.

## How to Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this project folder.
3. Commit and push your changes.
4. Open your repository's Settings.
5. Select Pages.
6. Choose Deploy from a branch.
7. Select the `main` branch and the `/ (root)` folder.
8. Save and wait for GitHub Pages to publish the website.

Your website URL should look similar to:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

Replace the example username and repository name with your own.
